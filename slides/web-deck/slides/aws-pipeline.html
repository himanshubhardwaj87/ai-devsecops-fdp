AI-Driven DevSecOps · ATAL FDP 2026 · Source: AWS CodePipeline run, us-east-1, 17 November 2026

This is the demo as it runs in an AWS account. Five stages in AWS CodePipeline. The security gate is the important one: a CodeBuild step that runs our six-stage pipeline, takes dependency vulnerability data from Amazon Inspector and triage from Claude on Amazon Bedrock, and returns an exit code. Then the image is built and pushed to the container registry tagged staging. Then the pipeline stops: a named person must approve before the same image is tagged for production. Both outcomes on this slide are real runs. A second path, not drawn here, sends an email when Amazon Inspector or GuardDuty reports something new after release; it notifies a person and changes nothing by itself. If someone asks why not deploy automatically: speed of detection is automated, the production decision is not.
