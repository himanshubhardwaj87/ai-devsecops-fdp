AI-Driven DevSecOps · ATAL FDP 2026

Switch to the terminal after this slide. ShopLite is a small Flask web service with seven deliberate flaws. A full AWS run takes several minutes, so start the vulnerable release before this section and let it run while you talk. Step 1: in the CodePipeline console show the SecurityGate stage failed, then open its build log: scan counts, the AI triage list, the three attackers, the failing controls and BLOCKED. Step 2: open report.html from the evidence folder in S3 and follow the SQL injection row from scanner severity to suggested fix. Step 3: open app/app.py and app_secure/app.py side by side; each flaw and fix is numbered in comments. Step 4: package and release the fixed app; show the gate passing, the staging image in ECR and the pipeline waiting at HumanApproval, then approve it yourself. Fallback if AWS or the network misbehaves: the interactive presentation shows the same real results, and the same pipeline runs on the laptop with python -m pipeline.run --target app --step. Commands are in aws/README.md.
