AI-Driven DevSecOps · ATAL FDP 2026

This is the slide for faculty to take away. The project is small, plain Python and free to run, so it fits a lab session. Lab 1 suits a secure coding or web technology course: students fix the seven flaws themselves with the pipeline as the marker. Lab 2 is a software engineering exercise in writing a check and its test. Lab 3 belongs in a machine learning course: add a feature, change the contamination setting, add a new synthetic attacker, and report precision and recall. Lab 4 is the most current: students act as attackers against the AI stage. Labs 1 to 3 need no API key or internet beyond the first install. Ask the audience which course they would place it in.
