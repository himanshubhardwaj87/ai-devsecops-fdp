AI-Driven DevSecOps · ATAL FDP 2026

Now open the security gate from the previous slide. Inside it: six stages, one command. Scan runs four scanners. Triage sends their output to a language model. Detect runs the Isolation Forest we just discussed. Comply maps what was found onto control frameworks. Gate reads a policy file and returns pass or block. Report writes an HTML dashboard. The important engineering point is the exit code: a CI system such as GitHub Actions or Jenkins only needs that one number to stop a merge. Everything is plain Python so students can read every stage.
