AI-Driven DevSecOps · ATAL FDP 2026

DevSecOps means security checks are part of the delivery pipeline, not a separate phase at the end. Read the row left to right: each stage has a security activity that can be automated. SAST is static analysis of source code; SBOM is a software bill of materials, the ingredient list of a build. Two directions matter. Shift left: catch problems early, when the fix is one line. Shield right: monitor in production, because no scanner catches everything. Our demo touches Code, Build, Release, Deploy and Monitor.
