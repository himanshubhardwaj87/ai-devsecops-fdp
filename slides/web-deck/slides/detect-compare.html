Two ways to spot an attack

Signature-basedBehaviour-based
It knowsPatterns of known attacksWhat normal looks like
It catchesKnown attacks, preciselyUnusual behaviour, including new attacks
It missesAnything without a ruleAttacks that look like normal use
Main costWriting and updating rulesFalse alarms to investigate

Use both: signatures for precision, behaviour for coverage.

AI-Driven DevSecOps · ATAL FDP 2026

Start part one. A signature is a rule such as 'block requests containing this string'. It is precise and explainable, and blind to anything new. A behaviour-based detector learns a baseline and reports deviations; it can catch an attack nobody has seen, and it pays for that with false alarms. Neither replaces the other. For students this is a nice link between a networks course and a machine learning course: the same problem seen as pattern matching and as anomaly detection.
