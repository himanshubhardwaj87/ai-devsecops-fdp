AI-Driven DevSecOps · ATAL FDP 2026

The FDP title mentions future trends, so close the content with questions that are still open and sized for a final-year project or an MTech thesis. Measuring triage: there is no agreed benchmark for whether an LLM's prioritisation matches expert judgment; building a labelled dataset is a contribution. Small local models: many organisations cannot send code outside, so how much capability is lost with an on-premises model? Explaining alerts: a user study with students as analysts is feasible. Attacking the defender: adversarial machine learning applied to security tools themselves. These are suggestions from practice, not a literature survey; invite the audience to add their own.
