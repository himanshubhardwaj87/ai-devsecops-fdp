Isolation Forest is a good first model to teach because the idea fits in one picture. Build many random trees; each tree keeps cutting the data along a random feature at a random value. A normal client sits in a crowd, so it takes many cuts to isolate it. An unusual client is isolated almost immediately. The average number of cuts becomes the anomaly score. It is unsupervised: we never show it an attack. In the demo each client becomes one row with the six features at the bottom. In scikit-learn the model is three lines of code, which makes it a practical lab exercise.
