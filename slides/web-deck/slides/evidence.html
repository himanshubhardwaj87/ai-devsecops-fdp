Part 3 · Continuous compliance

Compliance becomes a by-product of shipping.

Every build leaves a dated record: what was scanned, what was found, what was decided, and why.

Pause on this one. The traditional model is: build for a year, then collect evidence for the auditor. The continuous model is: every build writes its own evidence, so the audit question 'show me this control operated' is answered by pointing at the pipeline history. In the demo that record is the HTML dashboard and the result.json beside it; in AWS each build uploads them to S3 under its own build number. For students, the lesson is that compliance can be an engineering problem with tests, not only paperwork.
