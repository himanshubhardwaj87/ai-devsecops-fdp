AI-Driven DevSecOps · ATAL FDP 2026 · OWASP Top 10:2021, NIST SP 800-218 v1.1, ISO/IEC 27001:2022 Annex A

Continuous compliance is a mapping exercise. Each control in a framework asks a question, and the pipeline already holds the answer. OWASP A03, injection: do we have open SQL or command injection findings? NIST SSDF practice PW.7 asks that code be reviewed and analysed for vulnerabilities; the SAST run is that evidence. ISO 27001 Annex A control 8.8 covers technical vulnerability management; the dependency audit answers it. The demo evaluates 17 such controls. Be careful with the claim: this mapping is illustrative teaching material, and a real audit needs far more than tool output. Local context you can mention: CERT-In's 2022 directions require reporting certain incidents within six hours, and the Digital Personal Data Protection Act 2023 requires reasonable security safeguards; both push organisations towards evidence that is always current.
