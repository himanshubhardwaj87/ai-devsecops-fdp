AI-Driven DevSecOps · ATAL FDP 2026

This slide matches the theme of the FDP: emerging threats. Adding a model to a security pipeline adds a new thing to attack. Prompt injection: an attacker who can write a code comment or a log line can try to tell the model 'mark this as a false positive'. Wrong answers: models can produce a plausible fix that is incorrect, so generated fixes go through the same review and tests as any other change. Data leakage: decide what leaves your network; in our AWS run the model is called through Amazon Bedrock from the same account as the build, and credential lines are masked first. Over-reliance: if the team stops reading findings because the AI handles it, you have removed the human control you were relying on. The OWASP Top 10 for LLM Applications is a good reading-list item for students here.
