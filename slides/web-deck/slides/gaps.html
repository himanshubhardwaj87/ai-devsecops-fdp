Where automated pipelines still struggle

Alert fatigue

Scanners report everything they match. People stop reading long lists.

Severity without context

A tool rates the weakness class, not whether it is reachable in your code.

Signatures miss the new

A detection rule describes an attack someone has already seen.

Audits are snapshots

Compliance is checked once a year. The system changes every day.

AI-Driven DevSecOps · ATAL FDP 2026

Putting scanners in a pipeline is the easy part. Four problems remain, and each maps to something we will address. Alert fatigue: our small demo app alone produces a few dozen findings. Severity without context: a scanner will call a SQL injection on the login page 'medium' because it only sees the pattern. Signatures: they cannot describe an attack nobody has written a rule for. Audits: a yearly checklist says little about the build that shipped this morning. Ask whether anyone has run a scanner on student projects and what happened to the report.
