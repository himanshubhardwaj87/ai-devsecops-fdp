AI-Driven DevSecOps · ATAL FDP 2026

Four kinds of scanning, each looking at a different layer. Secret scanning looks for credentials in the repository. SAST, static application security testing, reads source code without running it; Bandit is the standard open-source tool for Python. SCA, software composition analysis, checks third-party packages against a vulnerability database; in AWS we send the package list to Amazon Inspector, and on a laptop the same stage uses the free pip-audit tool. IaC, infrastructure as code, checks deployment files. Everything except Inspector is free and open source, so a college lab can run the whole thing without an AWS account. The design lesson is normalisation: each tool has its own output format, and we convert everything into one record with a CWE, the Common Weakness Enumeration id, so the AI and the compliance stage have one input.
