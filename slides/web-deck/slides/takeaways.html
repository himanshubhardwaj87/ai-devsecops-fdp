Takeaways

Three things to remember

1

AI shortens the list. It does not make the release decision.

2

Every model in a pipeline needs guardrails and a fallback.

3

Compliance evidence should come out of every build, automatically.

AI-Driven DevSecOps · ATAL FDP 2026

Three sentences, one per part of the talk. One: the value of AI here is attention; it turned a flat list into an ordered one with reasons, and a written policy made the call. Two: we masked secrets, validated output and kept a rule-based fallback; treat a model like any other untrusted component. Three: the dashboard and the control table were produced by the same run that built the software. If the audience remembers only one thing, make it the first.
